# 售后打卡系统

- 这是独立项目，源码同步到 `Jaydon-Lidong/aftersales-field-management` 仓库根目录，以及 `shangzeng20020703/Shang` 仓库的 `Tegene/售后管理系统/`。
- 当前及后续售后功能修改只在本项目中进行。EHR 是历史源码来源；除非用户另行明确要求，不修改其代码、不向 EHR 仓库推送、不操作原系统部署或业务数据库。
- 主流程：读取 Tegene 项目库 → 售后经理分配主责区域组长（协管可留空、无需填写分配原因）→ 售后经理或有权管理项目的区域组长先保存组长和组员待配置名单 → 新建并关联现场轮休规则，整份名单冲突校验后启用 → 打开个人排班，按北京时间周一至周日预览并逐人逐日调整、确认发布 → 员工按当天唯一主项目规则打卡 → 项目考勤总览。项目组长自动列入名单；待配置项目对员工可见但不可打卡；跨区域未来项目调动须原项目方和接收方确认；已发布排班的改动须逐级审核。
- Tegene 项目接口只读；本项目的负责人、人员安排和考勤保存在售后系统。
- 不提交真实环境变量、凭据、本地数据库、上传附件、运行备份或业务截图。配置示例保留为空值或占位符。
- 本地启动：`python3 scripts/dev.py start`；状态：`python3 scripts/dev.py status`。完整检查：`./scripts/check.sh`，后端集成检查使用临时数据库。
