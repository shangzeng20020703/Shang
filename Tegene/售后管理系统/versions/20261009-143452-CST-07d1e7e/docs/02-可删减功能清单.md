# 售后管理系统——可删减功能清单

版本 V1.0｜2026-09-29｜共 **231 项候选功能**。全部保留在需求池，未替业务方作最终删减。

每项有固定编号。可以直接在“你的决定”列填写“保留 / 后置 / 删除 / 修改”；变更编号的决定不影响其他条目追踪。

**已有**＝找到实现；**改造**＝已有基础但须适配或修正；**部分**＝配置/局部实现或明确受限；**新增**＝售后设计建议；**可选**＝外围需求。S 编号见 [源码证据索引](04-源码证据索引.md)。源码存在不代表本次已运行通过。

**P0**＝首个可验收现场闭环建议必需；**P1**＝完整日常管理建议保留；**P2**＝进阶/选装。优先级只是开发建议，非用户已批准的上线范围。

来源分布：{'已有': 97, '改造': 45, '新增': 69, '部分': 19, '可选': 1}。阶段分布：{'P0': 134, 'P1': 73, 'P2': 24}。

删除前检查：模板不能删掉历史版本；关闭薪酬/假期余额后仍需保留考勤影响解释；停用通知渠道不应删除审批任务；关闭定位或照片策略后必须重新定义到场证据强度。

| 无客户门户 | 客户账号和外部自助确认 | 内部负责人确认；客户附件仅作为证据，不能冒充客户签收 |
| 无频繁复核 | 随机核验、定时核验任务 | 仍需显示最近证据时间；不能再宣传持续在场监控 |
| 无薪酬 | 调休余额、工资倍率、补贴费用 | 锁定服务月报及对外导出，不能删除原始时间证据 |
