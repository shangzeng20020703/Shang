- 本工作区是售后打卡系统 NO.2 独立代码线，基于私有仓库提交 `2c7a2e0ff5e128417311b1443e05e5e69a488b30`。开发分支为 `Jaydon-Lidong/aftersales-field-management` 的 `codex/aftersales-no2`，确定版本的公开源码副本放在 `shangzeng20020703/Shang/售后管理系统NO.2/`。原 `Tegene/售后管理系统/` 固定保留，不再同步 NO.2 更新；私有仓库 `main` 不自动合并 NO.2。
- 每次确定新版本，先在 NO.2 分支提交并运行完整检查，再创建北京时间编号标签，按该提交制作完整 Git 跟踪源码副本、SHA-256 清单和版本索引；不归档 `.runtime/` 中的演示账号、数据库或附件。
- 当前及后续售后功能修改只在本项目中进行。EHR 是历史源码来源；除非用户另行明确要求，不修改其代码、不向 EHR 仓库推送、不操作原系统部署或业务数据库。
- NO.2 由售后经理统一管理考勤、项目地点及审批，员工在全部有效地点打卡。考勤按北京时间自然月和规则交界时间结算四天休息额度。旧组长在新规则生效后使用员工权限，历史项目排班和流水供查询。
- Tegene 项目接口只读；本项目的负责人、人员安排和考勤保存在售后系统。
- 不提交真实环境变量、凭据、本地数据库、上传附件、运行备份或业务截图。配置示例保留为空值或占位符。
- 本地启动：`python3 scripts/dev.py start`；状态：`python3 scripts/dev.py status`。完整检查：`./scripts/check.sh`，后端集成检查使用临时数据库。
